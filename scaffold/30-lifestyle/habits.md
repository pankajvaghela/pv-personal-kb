# Habits

Standing things I want to keep doing. Not actions — those complete — and not goals, which arrive. A habit never finishes; it is either being kept or it is not.

One line per habit:

    - **<habit>** — <cadence> — <what counts>

For example:

    - **Gym** — 4×/week — a session, not a visit
    - **Reading** — daily — ten pages

Cadence is `daily`, `N×/week`, or `N×/month`. It has to be a number, because it is what "on track" is measured against, and a feeling cannot be measured.

**"What counts" is the part worth writing carefully.** "A session, not a visit." "Ten pages, not ten minutes." A habit with a vague definition is one you will argue with yourself about at eleven at night, and the argument is what kills it.

**The ticks are not in this file.** They go in the day's note under `## Habits`, which is where the day is already being written — `/pkb-end-of-the-day` fills them in. This file holds only what the habits *are*, so changing a cadence never rewrites history, and the daily notes stay the record of what actually happened.

## Dropped

Kept, not deleted — for the same reason the wishlist keeps dropped wishes. A habit that was abandoned is a fact about the last attempt, and it stops the same one being re-added every few months.
